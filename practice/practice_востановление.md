## Задание 2. Параметры восстановления

### Что требовалось
Задать параметры восстановления базы данных и выбрать состояние базы после восстановления.

### Что сделано
В окне параметров восстановления выбран вариант Leave the database ready to use by rolling back uncommitted transactions.

### Анализ
Выбор Leave the database ready to use by rolling back uncommitted transactions указывает Database Engine выполнить накат всех подтверждённых и откат всех неподтверждённых транзакций. После применения этой опции база данных будет находиться в согласованном состоянии и готова к использованию. Эта опция эквивалентна выполнению инструкции RESTORE DATABASE с опцией RECOVERY.

### Вывод
Опция RECOVERY завершает восстановление и делает базу доступной для работы.
