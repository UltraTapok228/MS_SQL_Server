## Задание 1. Основы транзакций
```sql
-- 1. Создание таблицы и наполнение данными
CREATE TABLE Accounts (
    AccountId INT PRIMARY KEY,
    OwnerName NVARCHAR(100),
    -- Добавляем CHECK для генерации ошибки при нехватке средств
    Balance DECIMAL(18, 2) CHECK (Balance >= 0) 
);

INSERT INTO Accounts VALUES
(1, 'Иванов', 5000.00),
(2, 'Петров', 3000.00),
(3, 'Сидоров', 10000.00);
GO

-- 2. Скрипт 1: Успешный перевод (COMMIT)
BEGIN TRANSACTION;
    -- Снимаем 1000 со счета 1
    UPDATE Accounts SET Balance = Balance - 1000 WHERE AccountId = 1;
    -- Зачисляем 1000 на счет 2
    UPDATE Accounts SET Balance = Balance + 1000 WHERE AccountId = 2;
COMMIT TRANSACTION;
GO

-- 3. Скрипт 2: Транзакция с ошибкой (ROLLBACK)
BEGIN TRANSACTION;
    -- Успешное снятие
    UPDATE Accounts SET Balance = Balance - 1000 WHERE AccountId = 3;
    
    -- Ошибка: попытка снять сумму, превышающую баланс (нарушение CHECK)
    UPDATE Accounts SET Balance = Balance - 99999 WHERE AccountId = 2;
    
-- Откатываем обе операции
ROLLBACK TRANSACTION;
GO
```

**Почему произошел откат?**
> Транзакция — это логическая единица работы, обладающая свойством атомарности (выполняются либо все действия, либо ни одного). При вызове команды ROLLBACK система отменяет все изменения в базе данных, сделанные в рамках этой транзакции, и возвращает данные к согласованному состоянию, которое было до команды BEGIN TRANSACTION.

## Задание 2. Обработка ошибок с TRY CATCH и XACT_ABORT
```sql
-- Попробуй выполнить скрипт сначала с ON, а затем с OFF
SET XACT_ABORT ON; 

BEGIN TRY
    BEGIN TRANSACTION;
        UPDATE Accounts SET Balance = Balance - 1000 WHERE AccountId = 1;
        
        -- Искусственная ошибка: деление на ноль
        DECLARE @Error INT = 1 / 0; 
        
        UPDATE Accounts SET Balance = Balance + 1000 WHERE AccountId = 2;
    COMMIT TRANSACTION;
END TRY
BEGIN CATCH
    -- Проверяем, есть ли открытая транзакция перед откатом
    IF @@TRANCOUNT > 0
        ROLLBACK TRANSACTION;

    -- Вывод системной информации об ошибке
    SELECT 
        ERROR_NUMBER() AS ErrorNum, 
        ERROR_MESSAGE() AS ErrorMsg;
END CATCH;
GO
```

**Разница режимов XACT_ABORT:**
* SET XACT_ABORT ON: Если инструкция T-SQL вызывает ошибку, вся транзакция автоматически завершается и немедленно выполняется ее полный откат.
* SET XACT_ABORT OFF (по умолчанию): В некоторых случаях выполняется откат только той инструкции, которая вызвала сбой, а сама транзакция остается открытой и продолжает обработку.

## Задание 3. Вложенные транзакции и SAVE TRANSACTION
```sql
CREATE TABLE TransferLog (LogId INT IDENTITY, LogMsg NVARCHAR(100));
GO

BEGIN TRANSACTION;
    -- 1: Списание
    UPDATE Accounts SET Balance = Balance - 1000 WHERE AccountId = 1;

    -- Сохраняем состояние после успешного Шага 1
    SAVE TRANSACTION SavePoint1;

    -- 2: Зачисление
    UPDATE Accounts SET Balance = Balance + 1000 WHERE AccountId = 2;

    -- 3: Запись в лог
    -- если запист не удалась, то отменяем шаг 2, и сохраняем шаг 1
    ROLLBACK TRANSACTION SavePoint1;

-- фиксация транзакии, запишется только шаг 1
COMMIT TRANSACTION;
GO
```
**Почему ROLLBACK TRANSACTION SavePoint1 не уменьшает @@TRANCOUNT?**
* Функция @@TRANCOUNT отслеживает общее количество открытых транзакций. Откат к точке сохранения (SAVEPOINT) отменяет лишь часть операций внутри текущей активной транзакции, но не закрывает саму транзакцию. Поскольку транзакция физически остается открытой и требует финального COMMIT или полного ROLLBACK, значение @@TRANCOUNT не изменяется.
