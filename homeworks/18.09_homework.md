## Задание 1. Функция со встроенными функциями

### Что требовалось
Создать функцию, которая показывает пример всех групп встроенных функций. В ДЗ отправить скриншот, где видны код и результат, через репозиторий.

### Что сделано
Создана скалярная функция dbo.ShowBuiltInFunctions. Она с помощью CONCAT собирает итоговый текст, применяя внутри встроенные функции по категориям: строковые, математические, даты и времени, преобразования, системные.

```sql
CREATE OR ALTER FUNCTION dbo.ShowBuiltInFunctions ()
RETURNS NVARCHAR(1000)
AS
BEGIN
    DECLARE @Result NVARCHAR(1000);
    
    -- CONCAT (строковая) собирает итоговый текст, применяя встроенные функции внутри
    SET @Result = CONCAT(
        '1. Строковые: UPPER = ', UPPER('sql'), ', LEN = ', LEN('Колледж'), CHAR(10),
        '2. Математические: ROUND(PI) = ', ROUND(PI(), 2), ', POWER(2,3) = ', POWER(2, 3), CHAR(10),
        '3. Дата и время: GETDATE = ', CONVERT(VARCHAR, GETDATE(), 104), ', YEAR = ', YEAR(GETDATE()), CHAR(10),
        '4. Преобразования: CAST = ', CAST(123.45 AS INT), ', ISNULL = ', ISNULL(NULL, 'Пусто'), CHAR(10),
        '5. Системные: DB_NAME = ', DB_NAME()
    );

    RETURN @Result;
END;
GO
```

### Анализ
| Категория | Использованные функции |
|---|---|
| Строковые | UPPER, LEN, CONCAT |
| Математические | ROUND, PI, POWER |
| Дата и время | GETDATE, YEAR, CONVERT |
| Преобразования | CAST, ISNULL |
| Системные | DB_NAME |

### Вывод
Все результаты встроенных функций объединяются в одну строку, возвращаемую скалярной функцией.

## Задание 2. Процедура: разница между выпускающимися и поступившими студентами

### Что требовалось
Создать процедуру, которая считает разницу между выпускающимися студентами и поступившими.

### Что сделано
Создана процедура dbo.CalcStudentsDiff. Поступившими считаются студенты с максимальным годом поступления (EnrolledYear), выпускающимися — с минимальным. Процедура считает количество в каждой группе, вычисляет разницу и выводит три значения.

```sql
CREATE OR ALTER PROCEDURE dbo.CalcStudentsDiff
AS
BEGIN
    DECLARE @EnrolledCount INT;
    DECLARE @GraduatingCount INT;
    DECLARE @Difference INT;

    -- подсчет поступивших
    SELECT @EnrolledCount = COUNT(*) 
    FROM Students 
    WHERE EnrolledYear = (SELECT MAX(EnrolledYear) FROM Students);

    -- подсчет выпускников
    SELECT @GraduatingCount = COUNT(*) 
    FROM Students 
    WHERE EnrolledYear = (SELECT MIN(EnrolledYear) FROM Students);

    -- разница между ними
    SET @Difference = @EnrolledCount - @GraduatingCount;

    -- вывод
    SELECT 
        @EnrolledCount AS [Поступившие (Свежий набор)],
        @GraduatingCount AS [Выпускающиеся (Старший курс)],
        @Difference AS [Разница];
END;
GO
```
