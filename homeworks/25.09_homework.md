# Лабораторная работа. Представления (Views)

Создание модифицируемых и только читаемых представлений в базе view.

---

## Задание 1. Подготовка тестовых данных

 
### Что требовалось
Подготовить тестовые таблицы Groups и Students со связью по GroupID и наполнить их данными.

### Что сделано
Созданы таблицы dbo.Groups (GroupID, GroupName) и dbo.Students (StudentID, FullName, GroupID с внешним ключом на Groups). Перед созданием таблицы удаляются, если уже существуют. Добавлены две группы и три студента.

```sql
USE [view];
GO

-- 1 подготовка тестовых 
IF OBJECT_ID('dbo.Students', 'U') IS NOT NULL DROP TABLE dbo.Students;
IF OBJECT_ID('dbo.Groups', 'U') IS NOT NULL DROP TABLE dbo.Groups;

CREATE TABLE dbo.Groups (
    GroupID INT IDENTITY(1,1) PRIMARY KEY,
    GroupName NVARCHAR(50) NOT NULL
);

CREATE TABLE dbo.Students (
    StudentID INT IDENTITY(1,1) PRIMARY KEY,
    FullName NVARCHAR(100) NOT NULL,
    GroupID INT FOREIGN KEY REFERENCES dbo.Groups(GroupID)
);

-- заполнение данными
INSERT INTO dbo.Groups (GroupName) VALUES ('Группа ИТ-1'), ('Группа ИТ-2');
INSERT INTO dbo.Students (FullName, GroupID) VALUES 
('Иванов Иван', 1), 
('Петров Петр', 2), 
('Сидоров Сидор', 1);
GO
```

### Вывод
Подготовлена база из двух связанных таблиц для демонстрации представлений.

## Задание 2. Создание представлений

 
### Что требовалось
Создать три представления: одно модифицируемое (updatable) и два только для чтения — с JOIN и с агрегацией. Проверить работу модифицируемого представления.

### Что сделано
Созданы три представления:

- vw_Updatable_Students — модифицируемое, обращается к одной таблице, без GROUP BY и DISTINCT.
- vw_Student_Full_Info — только для чтения, содержит JOIN, выводит студентов с названием группы.
- vw_Group_Statistics — только для чтения, содержит агрегацию, считает студентов в каждой группе.

Затем через модифицируемое представление добавлен новый студент, после чего выполнены проверочные SELECT.

```sql
-- Представление 1: Модифицируемое (Updatable View)
-- Требование: должно обращаться только к одной таблице, без GROUP BY и DISTINCT.
CREATE OR ALTER VIEW vw_Updatable_Students AS
SELECT 
    StudentID, 
    FullName, 
    GroupID
FROM dbo.Students;
GO

-- Представление 2: Только для чтения (содержит JOIN)
-- Выводит полные данные о студентах с текстовым названием их группы.
CREATE OR ALTER VIEW vw_Student_Full_Info AS
SELECT 
    s.StudentID, 
    s.FullName, 
    g.GroupName
FROM dbo.Students s
JOIN dbo.Groups g ON s.GroupID = g.GroupID;
GO

-- Представление 3: Только для чтения (содержит агрегацию)
-- Подсчитывает количество студентов в каждой группе.
CREATE OR ALTER VIEW vw_Group_Statistics AS
SELECT 
    g.GroupName, 
    COUNT(s.StudentID) AS TotalStudents
FROM dbo.Groups g
LEFT JOIN dbo.Students s ON g.GroupID = s.GroupID
GROUP BY g.GroupName;
GO


-- 3. Проверка работы модифицируемого представления

-- добавление нового студента прямо через представление
INSERT INTO vw_Updatable_Students (FullName, GroupID) 
VALUES ('Новый Студент', 2);

-- проверка результата
SELECT * FROM vw_Updatable_Students;
SELECT * FROM vw_Group_Statistics;
```

### Анализ

| Представление | Тип | Почему |
|---|---|---|
| vw_Updatable_Students | Модифицируемое | Одна базовая таблица (Students), нет агрегации и уникальности — доступны INSERT, UPDATE, DELETE |
| vw_Student_Full_Info | Только чтение | JOIN связывает таблицы по ключам, скрывает числовые ID и выводит понятный текст |
| vw_Group_Statistics | Только чтение | GROUP BY и COUNT делают его недоступным для изменения |

### Вывод
Представление можно изменять напрямую, только если оно опирается на одну таблицу и не содержит агрегации, DISTINCT и подобных конструкций. Представления с JOIN и GROUP BY служат для чтения и отчётов.

**Ключевые принципы:**
1. Представление — сохранённый SELECT, не хранящий данных.
2. Модифицируемое представление — одна таблица, без агрегации, GROUP BY и DISTINCT.
3. JOIN и агрегатные функции делают представление «только для чтения».
4. Представления скрывают технические детали (ID) и упрощают чтение данных.
