**Создание БД**
**\* Таблицы: хранят собственно данные**
**\* Представления: выражения языка SQL, которые возвращают набор данных в виде таблицы**
**\* Хранимые процедуры: выполняют код на языке SQL по отношению к хранимым БД**
**\* BLOB-поля: данные в формате больших двоичных данных**
**\* Иные метаданные**

**Какие есть типы данных:**  
\* Целочисленные типы данных - хранятся числа  
\- Tinyint  
\- Smallint  
\- Int  
\- Bigint

**\* Типы данных для хранения дробных чисел**  
\- Bit  
\- Text

\- Image  
\- RowGUID  
\- SQL\_Variant

**\* Типы данных даты и времени**  
\- Datetime  
\- SmallDatetime

**\* Денежные типы данных для хранения финансовой информации**  
\- Money  
\- Smallmoney

**\* Символьные типы**  
\- Char()  
\- Varchar(n)  
\- Nvarchar(n)
